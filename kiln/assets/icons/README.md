# File icons

Place filetype icons in this folder using lowercase extensions, including the leading dot.

Expected filenames:

- `.blend.png`
- `.spp.png`
- `.psd.png`
- `.png.png`
- `.jpg.png`
- `.jpeg.png`
- `.exr.png`
- `.tif.png`
- `.tiff.png`
- `.fbx.png`
- `.obj.png`
- `.abc.png`
- `.usd.png`
- `.wav.png`
- `.mp4.png`

Additional filetypes can use the same pattern, for example `.ma.png`, `.mb.png`, or `.mov.png`.

Use PNG files with transparent backgrounds where possible. A square image is preferred; 128x128 or 256x256 works well.

If an icon is missing, Kiln will continue using its generated extension tile.
